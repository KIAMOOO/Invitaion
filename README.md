# Сағибек ата — 80 жас

Цинематичное анимированное приглашение на 80-летний юбилей в традиционном казахском стиле.

## 🌐 Demo

После деплоя на GitHub Pages: `https://KIAMOOO.github.io/Invitaion/`

## ✨ Возможности

- Кинематографичная анимация с эффектом Ken Burns, вращающейся мандалой и парящими частицами
- Аутентичные казахские орнаменты (қошқар мүйіз)
- Большая золотая цифра «80» в медальоне с двумя вращающимися кольцами
- Поддержка казахской музыки (домбра/қобыз)
- Кнопки управления: пауза/продолжить, вкл/выкл звук, перезапуск
- Экспорт записи видео в формате 1080×1920 (вертикальное, для телефонов)

## 📁 Файлы

- `index.html` / `invitation.html` — основной файл приглашения
- `music.mp3` — фоновая музыка (домбра)
- `ИНСТРУКЦИЯ.md` — подробная инструкция для пользователя

## 🚀 Запуск локально

Просто откройте `index.html` в Chrome или Edge.
